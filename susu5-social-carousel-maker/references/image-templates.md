# Image Layout Templates

Image templates describe composition, text placement, and visual hierarchy. Combine one image template with one visual style template to assemble the final prompt.

## TEMPLATE-COVER-HOOK-01

Use for: `PAGE-COVER`

Layout:

- dominant headline in upper-middle safe area
- one short subtitle below headline
- 1-3 keyword chips or benefit tags in lower-middle
- one simple visual anchor related to the topic
- generous margins

Prompt clause:

```text
Large headline in the upper-middle safe area, short subtitle below, three keyword chips near the lower-middle area, simple visual anchor related to the topic, generous safe margins, cover-like click appeal.
```

## TEMPLATE-COVER-PHOTO-02

Use for: `PAGE-COVER`, story or product content.

Layout:

- large editorial photo or illustration anchor
- headline layered in a clean safe area
- minimal subtitle
- no dense body text

Prompt clause:

```text
Editorial cover composition with one strong photographic or illustrated visual anchor, headline placed in a clean readable safe area, minimal subtitle, strong first-glance impact.
```

## TEMPLATE-BOLD-TYPE-COVER-03

Use for: `PAGE-COVER`, especially with `STYLE-BOLD-CURVED-TYPE` or `STYLE-BOLD-SWISS-POSTER`.

Layout:

- one giant Chinese word or 2-4 character phrase as the main visual
- one small metadata line or topic label
- one accent block or controlled curved accent shape
- strict grid, strong cropping, and large negative space
- no diagrams, no sidebars, no dense body copy

Prompt clause:

```text
Bold typography cover layout with one gigantic Chinese word or short phrase as the main image, one small metadata line, strict grid, large negative space, one accent block or restrained curved accent shape, strong poster crop, no diagrams, no sidebars, no dense information.
```

## TEMPLATE-CONTENT-CARD-01

Use for: `PAGE-INSIGHT`, `PAGE-METHOD`, `PAGE-PRODUCT`

Layout:

- title at top
- central content block
- 2-3 supporting bullets or cards
- optional small icon per bullet

Prompt clause:

```text
Clean content-card layout with title at top, one central idea block, 2-3 supporting bullet cards, clear spacing, simple icons if useful, easy to scan in two seconds.
```

## TEMPLATE-CHECKLIST-01

Use for: `PAGE-CHECKLIST`

Layout:

- title at top
- checklist rows
- simple check marks or numbered markers
- optional bottom reminder

Prompt clause:

```text
Structured checklist layout with clear rows, simple check markers, strong spacing, short readable items, saveable utility-card feeling.
```

## TEMPLATE-STEPS-01

Use for: `PAGE-STEPS`

Layout:

- title at top
- vertical or diagonal sequence
- step numbers 01-04 or 01-05
- arrows or connecting line

Prompt clause:

```text
Step-by-step tutorial layout with numbered markers, clear vertical flow, simple arrows or connecting line, each step visually separated and easy to follow.
```

## TEMPLATE-COMPARISON-01

Use for: `PAGE-COMPARISON`

Layout:

- two columns
- left and right labels
- contrast points
- highlight recommended or improved side

Prompt clause:

```text
Two-column comparison layout with clear left/right labels, immediate contrast, concise points on each side, one accent color highlighting the recommended or improved side.
```

## TEMPLATE-DATA-HERO-01

Use for: `PAGE-DATA`

Layout:

- one giant number or metric
- short interpretation
- small source note if approved
- optional simple chart

Prompt clause:

```text
Data hero layout with one giant number as the visual center, short interpretation, optional simple chart, high-trust analytical composition, minimal decoration.
```

## TEMPLATE-CASE-STORY-01

Use for: `PAGE-CASE`

Layout:

- scene title
- three story beats: situation, action, result
- optional timeline or mini cards

Prompt clause:

```text
Case-story layout with three compact beats: situation, action, result. Use simple timeline or mini cards, concrete and credible, not overly dramatic.
```

## TEMPLATE-QUOTE-01

Use for: `PAGE-QUOTE`

Layout:

- quote dominates the page
- small supporting line
- minimal visual metaphor or texture

Prompt clause:

```text
Editorial quote layout with the quote as the visual center, large expressive typography, small supporting line, strong whitespace, shareable and thoughtful.
```

## TEMPLATE-SUMMARY-CTA-01

Use for: `PAGE-SUMMARY`

Layout:

- final takeaway
- short recap or 3 mini tags
- interaction prompt
- calm closing composition

Prompt clause:

```text
Closing summary layout with clear final takeaway, compact recap, simple save/comment call to action, visually consistent but slightly calmer and more resolved.
```

## TEMPLATE-MINDMAP-01

Use for: `PAGE-METHOD`, `PAGE-INSIGHT`

Layout:

- central concept
- 3-5 connected branches
- labels kept short

Prompt clause:

```text
Structured mindmap layout with one central concept and 3-5 connected branches, short labels, clear hierarchy, logical framework feeling.
```

Rules:

- Choose templates by page role first, then adapt to content.
- Do not use data templates for non-data pages.
- Do not use photo-heavy templates when the page has dense text.
- For one carousel, repeat a few templates with variation; do not use a completely different layout language on every page.
