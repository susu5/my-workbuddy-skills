# Quality Checklist

Run this before delivery.

## P0 - Must Fix

- Full carousel was generated before user approved content, size, style, and 3 samples.
- Image2 prompt omitted visual style or image layout template.
- Different pages look like different brands.
- In-image text is unreadable or heavily distorted.
- Image includes watermark, QR code, fake logo, page number, signature, or random text.
- Claims are exaggerated, unsupported, or outside user-provided evidence.
- Data page uses invented data.

## P1 - Should Fix

- Cover hook is weak or too abstract.
- Page has more than one core idea.
- Body copy is too dense for mobile.
- Style choice does not match audience or topic.
- Layout template does not match page role.
- CTA is too pushy for the content type.

## P2 - Improve If Time Allows

- Captions/hashtags could be sharper.
- Visual metaphor could be more specific.
- Page sequence could have better rhythm.
- Repeated templates need subtle variation.

## Final Delivery Checklist

- Page plan approved.
- Size approved.
- Style approved.
- 3 samples approved.
- Final image prompts assembled.
- Final images generated or ready for generation.
- Publishing title/caption/hashtags included.
- Risks and assumptions noted.
